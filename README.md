# homebrew-tools

Homebrew tap for my CLI tools.

```bash
brew tap mnich/tools
brew install towebp   # batch JPG/PNG -> WebP
brew install toavif   # batch JPG/PNG -> AVIF
```

| Formula | Repository |
| --- | --- |
| `towebp` | [mnich/towebp](https://github.com/mnich/towebp) |
| `toavif` | [mnich/toavif](https://github.com/mnich/toavif) |
